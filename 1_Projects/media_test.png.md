# App Analytics Dashboard - Market Data Bridge

*A developer portal interface displaying application performance metrics and usage analytics for the Market Data Bridge application.*

This dashboard shows the "App Analytics" tab with key performance indicators organized into four sections: Time Frame (set to "Last Hour"), App Usage (366 total API calls, 366 average calls per hour), App Health (121.11 ms average response rate, 366 total errors, 100% error rate), and Device Analytics (1 unique user IP, 366 unknown device types, 366 requests from United States). The interface uses a clean, structured layout with clear section headers and metric labels aligned to the left with corresponding values on the right.
